# Kronos：效果证据与边界核验

核验日期：2026-10-06。仅阅读作者论文 arXiv v1 和官方仓库；未下载权重、未训练、未复现预测或回测。仓库当前默认分支为 `master`，核验提交为 `67b630e67f6a18c9e9be918d9b4337c960db1e9a`。

1. **身份与数据范围：面向金融 K 线的生成式预测模型。** 输入历史开高低收、成交量、成交额（OHLCVA）和时间，生成未来 K 线数值；可派生收益率、波动率预测，并生成合成行情。论文报告预训练数据约 121.1 亿条记录、45 个全球交易所、7 个频率（1分钟、5分钟、15分钟、30分钟、1小时、日、周），资产包括股票/ETF、加密资产、永续合约、中国期货、外汇和指数。数据表估计总资产数 96,569；各市场起始时间不同，不能把所有序列都当作自同一年开始。预训练截止 2024-06，测试期从 2024-07 开始。[论文方法](https://arxiv.org/html/2508.02739v1#S3.SSx3)、[数据统计 Table 13](https://arxiv.org/html/2508.02739v1#A8.T13)、[预测实验设置](https://arxiv.org/html/2508.02739v1#A4.SSx3.SSS0.Px1)

2. **论文有预测优势证据，但“提升 93%”不是胜率或收益率。** 作者与 25 个基线比较，价格序列和收益预测测 IC / RankIC（线性/秩相关性）；波动率测 MAE / R²；合成行情测分类器可辨别程度、分布可视化及“合成数据训练、真实数据测试”。摘要的价格 RankIC 相对领先通用时序模型提高 93%、相对最佳非预训练基线提高 87%，属于相对相关性指标提升。Table 14/15 中平均价格 RankIC：Kronos-large 0.0267、base 0.0258、small 0.0254，对比 Time-MOE 较大模型 0.0138、TimesNet 0.0143；这些绝对值并不是“预测准确率”。各市场/任务并非全胜。[任务与指标](https://arxiv.org/html/2508.02739v1#A4.SSx1)、[完整价格结果 Table 14](https://arxiv.org/html/2508.02739v1#A8.T14)、[完整价格结果 Table 15](https://arxiv.org/html/2508.02739v1#A8.T15)

3. **历史回测包含交易成本，但只证明特定模拟设置的结果。** 论文的投资模拟是 A 股 CSI300/CSI800 成分股上的做多策略：日线回看90天，预测10天收盘价的均值转为收益信号；CSI300 持有前50只、每天最多换5只，CSI800 持有前200只、每天最多换10只，最低持有5天；每笔交易计0.15%成本，评价 AER（年化超额收益）和 IR（信息比率）。官方新增微调演示代码使用买入0.1%、卖出0.15%、最低5元，并分别报告含/不含成本收益；这与论文费用设定不同。未从论文找到完整滑点/市场冲击建模证据，不能把模拟收益视为实盘保证。[论文投资模拟设置](https://arxiv.org/html/2508.02739v1#A4.SSx3.SSS0.Px3)、[已核验代码](https://github.com/shiyu-coder/Kronos/blob/67b630e67f6a18c9e9be918d9b4337c960db1e9a/finetune/qlib_test.py)

4. **泛化证据需要保留原文中的不确定性。** 论文明确使用预训练后时间段测试，也将印尼、马来西亚、台湾交易所列为 OOD（分布外）市场；但论文的总数据统计表同时列出这三个市场，并未在所核验实验段落解释训练时排除方式。因此可以说作者报告了 OOD 评测，不能强化为已独立证实的未见市场泛化。全部结果来自作者研究，当前没有本地独立复现实验。另一个可用性边界：论文效果涉及 499.2M 的 large 模型，而当前官方模型表标记 large 未开放；已开放 mini/small/base，不能把 large 的最佳分数直接当作下载 small 就能达到的效果。[实验市场设置](https://arxiv.org/html/2508.02739v1#A4.SSx3.SSS0.Px1)、[数据总表](https://arxiv.org/html/2508.02739v1#A8.T13)、[官方 Model Zoo](https://github.com/shiyu-coder/Kronos#-model-zoo)

5. **适合量化研究与预测功能原型，距离自动交易产品还有明确工程步骤。** 官方 README 称 Qlib 微调/回测是简化演示，提醒需要组合优化、因子中性化、仓位与风险管理、交易成本/滑点/市场冲击；模型本身给的是行情预测而非可直接执行的稳定 alpha。输入没有新闻、财报或订单簿等外生信息；多路径采样并平均可降低生成随机性，但也增加推理计算量。将它接入自己的行情源、严格按时间划分数据、比较简单基线、模拟费用与成交限制后，才能判断具体品种/频率是否值得用。[官方微调与生产注意事项](https://github.com/shiyu-coder/Kronos#-finetuning-on-your-own-data-a-share-market-example)、[论文多采样研究](https://arxiv.org/html/2508.02739v1#S4.SSx4)

可用于短答的结论：**这是一个把历史金融 K 线当作“语言”来学习的小模型系列，能预测未来价格和量、估计波动率、生成模拟行情，主要给量化研究或交易工具做底层预测。论文有作者评测和含成本历史回测，但不等于拿来就能稳定赚钱。**
